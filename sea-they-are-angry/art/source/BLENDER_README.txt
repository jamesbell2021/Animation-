SEA THEY ARE ANGRY — BLENDER CHARACTER STARTER PACK

Contents: four keeper GLB models, combined lineup, boat hook, and setup_blender_scene.py.

To create a Blender project:
1. Extract this ZIP to a folder.
2. Open Blender 3.6 or newer.
3. Go to the Scripting workspace and open setup_blender_scene.py.
4. Click Run Script.
5. The script imports the four keeper models, arranges them in a lineup, adds a ground plane, studio lighting and camera, and saves sea_they_are_angry_keepers.blend in the same folder.

You can also import each GLB directly using File > Import > glTF 2.0 (.glb/.gltf).

Important: These are starter meshes, not finished production characters. They are not rigged or animated. The setup script does not create a skeleton. Blender is not installed in the current generation environment, so the .blend file must be generated by running the script inside Blender.
