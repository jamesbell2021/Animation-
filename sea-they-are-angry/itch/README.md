# The itch.io pack

Everything for the game's itch.io page, for version 1.3.1.

- `PAGE.md`: what to type into each field of itch's project form, the tags, the order of
  the screenshots, and a colour theme.
- `description.html`: the page's description. Open it in a browser and copy it into itch.
- `UPLOAD.md`: how to upload the builds (by hand or with butler).
- `art/`: the cover (630x500), the banner (960x320) and a square icon (512x512).
- `screenshots/`: eleven 1280x720 screenshots, numbered for reference (the upload order
  is in `PAGE.md`).

The downloads themselves are built into `build/itch/` (not kept in git).
