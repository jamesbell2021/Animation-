# Credits

**Zero Star Hotel**, a 3BL_Indie game.

Made by James, Aaron, Connor and Bonnie.

- Made with Godot Engine (godotengine.org/license).
- All characters, scenery, icons, sound effects, music and voices are generated in code. The
  game ships no third-party assets.
- The character rig, audio synthesisers and UI kit are shared with Lookee Lookee Tycoon, by the
  same studio.
- Text uses Godot's built-in default font (Open Sans, SIL Open Font License 1.1).

The in-game credits screen (main menu → Credits) and the 3BL_Indie splash live in `studio/`.
