# Twelve · Sprite Animation Lab

Level 3 Games · Skills Development Unit A1

## Publish on GitHub Pages
1. Create a new public repository on github.com (e.g. `sprite-lab`).
2. Upload `index.html` to the root of the repository (Add file → Upload files → Commit). It is fully self-contained — nothing else to upload.
3. Go to Settings → Pages. Under "Build and deployment", set Source to "Deploy from a branch", Branch to `main`, folder `/ (root)`, then Save.
4. After a minute or two the site is live at `https://<your-username>.github.io/sprite-lab/`.

Share that link with students. It works on phones, tablets and laptops, and can be added to a phone home screen (Share → Add to Home Screen).

## Updating
Re-export `index.html` and upload it over the old one. Pages republishes automatically.

## Note on assets
All animations are built in code — no third-party art, so it is safe to publish publicly.
