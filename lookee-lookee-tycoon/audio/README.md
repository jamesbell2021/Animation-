# Drop-in audio

All audio is synthesised at runtime. To use recordings instead, add OGG Vorbis files:

- `voice/hello_chicken_nugget.ogg`, `voice/very_good_very_nice.ogg`, `voice/lookee_lookee.ogg`,
  `voice/policia.ogg`, `voice/hey.ogg` (the Voice Pitch slider still applies)
- `sfx/<name>.ogg` for any name in `scripts/audio/sfx_synth.gd` (`coin`, `whistle`, `siren`...)
- `music/beach.ogg`, `music/chase.ogg` (looped automatically)
